# Ontology Author contributor guidance

Follow [AGENTS.md](AGENTS.md), the shared contributor/agent guide.

Core Product v1 is frozen. The current authorities are:

- [Core baseline and application handoff](docs/CORE_PRODUCT_V1_BASELINE.md)
- [Core completion contract](docs/CORE_PRODUCT_V1_COMPLETION_CONTRACT.md)
- [Architecture](docs/ARCHITECTURE.md)

Applications own domain semantics and workflows. Reopen core only for a concrete
requirement that existing primitives cannot honestly express without violating
a frozen guarantee. Do not treat historical research, old prompts, or package
layout as architecture authority. Canonical publication retains each sealed
revision at a fresh address; legacy replacement APIs remain compatibility only.

Use the verification commands in AGENTS.md. Do not launch live model experiments
or publish releases without explicit authorization.
