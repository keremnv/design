# Evaluator-only artifacts

These files define the intended world, hidden questions, expected semantic consequences, and scoring rules for `grain-traceability-v1`. They must not be mounted in the constructor workspace or supplied to a downstream consumer operating under the raw-evidence condition.

The ledger was authored first. Host-visible files were then projected from it using independent operational schemas and local identifiers. The ledger is authoritative for adjudication, not a claim that an agent should be able to read it.
