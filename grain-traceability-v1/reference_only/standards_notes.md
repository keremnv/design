# Comparator standards and publication notes

These are reference materials for the human comparator only. They are not construction-host inputs and are not copied into the benchmark.

- NIST / ASME: Ameri, Wallace, Yoder, and Riddick, *Agri-Food Supply Chain Traceability Supported by a Formal Ontology: A Grain Elevator to Processor Use Case* (2023): <https://www.nist.gov/publications/agri-food-supply-chain-traceability-supported-formal-ontology-grain-elevator-processor>
- NIST / ASME: Ameri, Wallace, Yoder, and Riddick, *Enabling Traceability in Agri-Food Supply Chains Using an Ontological Approach* (2020 publication page): <https://www.nist.gov/publications/enabling-traceability-agri-food-supply-chains-using-ontological-approach-0>
- GS1 EPCIS: <https://ref.gs1.org/standards/epcis/>
- GS1 CBV: <https://ref.gs1.org/standards/cbv/>
- IOF Supply Chain Reference Ontology: <https://spec.industrialontologies.org/ontology/supply-chain/SupplyChainReferenceOntology/>

The conventional comparator borrows conceptual guidance from these materials while remaining a benchmark-specific semantic model. It is not claimed to be an implementation of any one standard.
