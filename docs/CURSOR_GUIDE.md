# Cursor with Ontology Author

Use the optional [agent attachment workflow](AGENT_CLIENTS.md). From this
checkout, install with `uv tool install .`; from the target project root,
run `author attach cursor`. This writes a native instruction rule, not an MCP
server configuration. Core v1 does not require Cursor or a live LLM.

Repository contributors should follow [AGENTS.md](../AGENTS.md) and the
[frozen Core v1 baseline](CORE_PRODUCT_V1_BASELINE.md). The attached runtime
capability preserves legacy create/rebuild commands; those replacement paths
do not by themselves retain independently addressable historical revisions.

The superseded graph/MCP instructions are preserved only as
[historical research](research/archive/CURSOR_GRAPH_GUIDE.md).
