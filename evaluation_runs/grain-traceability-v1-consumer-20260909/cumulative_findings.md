# Cumulative findings

## Executive synthesis

The archived experiments and the frozen grain experiment support a conditional compilation-and-reuse claim, not a universal accuracy or cost claim.

When a World contains purpose-relevant, evidence-supported meaning at a usable grain, fresh consumers repeatedly operate without native-source access and shift from source parsing/reconciliation toward semantic schema discovery, semantic querying, provenance inspection, and task reasoning. The grain Worlds preserve 9/10 frozen novel question consequences in both independent construction families and avoid all false closures. They do not recover the unsupported hidden 15,000/11,000 kg allocation, and they omit the CQ-only Spout 3 field. The first omission is a benchmark/evaluator defect; the second is a real finer-grain coverage limit that does not defeat the short operational purpose.

## 1. What prior experiments already demonstrated

Prior work already demonstrated all of the following, with important boundaries:

- An organically constructed World can retain RAW correctness in a downstream source-free consumer. The Philips frontier campaign did this for two independently constructed Worlds and the same analyst task set.
- A World can outperform RAW on particular programming and semantic-integration tasks. BOM RAW-vs-World programming reported strong World advantages, although contamination and task/model differences limit pooling.
- RAW can outperform an inadequate World. Philips C2 under-closed serial positives; the end-to-end Composer campaign measured RAW 36/36 establishable versus WORLD 32/36, with World unsupported closures in some non-establishable cases.
- Source independence is repeatedly demonstrated. Philips, BOM, end-to-end, NPDES, NIH, and grain World/Product arms all used physical isolation and recorded zero native-source reads in World conditions.
- Repeated native-source semantic reconstruction can be eliminated operationally. RAW consumers independently parse source formats and reconstruct joins/rules; World consumers query compiled relations and inspect stored grounding/purpose limits.
- Work character shifts reliably, but tool count does not necessarily fall. World consumers spend work learning the World’s representation and uncertainty policy; RAW consumers spend it discovering and reconciling native source systems.
- Prior work did not provide a clean comparison between an organically constructed World and a deliberately engineered conventional reference semantic layer. Grain supplies the first explicit reference arm, with the NQ-01 reference-materialization caveat documented below.

The full campaign-level recovery is in [prior_reuse_evidence.md](prior_reuse_evidence.md) and its machine-readable companion.

## 2. What grain replicates

Grain replicates the prior source-independence and work-character findings under a new heterogeneous operational corpus and the current Ontology Author architecture:

- RAW consumers read and interpreted the CSV, JSON, and Markdown sources directly.
- REFERENCE, OA-1, and OA-2 consumers had no native evidence mounted and recorded zero native-source reads.
- OA-1 and OA-2 independently inspected their own SQLite semantic surfaces, grounding sidecars, unresolved requirements, custody/ownership records, and completeness claims.
- All eight final consumers completed two replicates each.
- All conditions preserved the three hardest negative/uncertain boundaries: no invented OUT-5003 receipt, no `N3 / EF-18?` identity closure, and no HFM-E negative from HFM-N completeness.

It also replicates the prior conditional-correctness result: Worlds can preserve most RAW-load-bearing consequences, but the World must contain the needed grain and the consumer must understand its representation.

## 3. What grain genuinely adds

Grain adds four new results.

First, two materially different organically constructed Worlds converged on the same downstream consequence profile without sharing schema, construction code, or evaluator feedback: 9/10 frozen novel consequences complete, the same NQ-01 partial, zero false closures, zero incorrectly unresolved answers, and zero native-source reads.

Second, grain provides an explicit REFERENCE consumer arm. The reference arm produced the frozen-gold 15,000/11,000 split and 10/10 question results, while both Worlds and RAW produced 9/10 complete results. This is useful evidence that a conventional semantic layer can make a hidden consequence easy to consume, but it is not clean evidence that the split is source-grounded: the reference instance inherited it from evaluator canonical truth even though the host evidence does not establish it.

Third, grain separates benchmark coverage from purpose sufficiency. The frozen evaluator verdict remains `PARTIALLY_SUPPORTED`, but the post-audit purpose-only judgment is `SUPPORTED`. This distinction was not explicit in the earlier consumer comparisons.

Fourth, grain exposes a correlated omission that is diagnostic rather than simply a constructor error. Both Worlds model the loadout event but omit Spout 3, showing a shared abstraction boundary around equipment-point grain. Both also refuse per-source quantities for an evidence record that explicitly withholds them, showing that correlated conservative behavior can be correct even when frozen gold says partial.

## 4. Correctness: does evidence support `World >= RAW`?

No general inequality is justified. The strongest defensible statement is:

> On this grain question set, both organically constructed Worlds preserved the same nine fully supported frozen-gold question consequences as RAW, with no false closures; an engineered reference arm matched the frozen gold on all ten, but its extra NQ-01 quantity split is not host-evidence-grounded.

This is conditional parity on supported consequences, not universal World superiority. Prior campaigns show both World advantage and RAW advantage depending on World adequacy, task design, and consumer behavior.

## 5. Source independence and semantic reconstruction

Across the cumulative archive, World consumption repeatedly succeeds with native sources unavailable. Grain adds two independent World families to that pattern. Consumers did not reopen evidence files to rediscover:

- the receipt-ticket to bin-movement identities;
- carrier bill to processor receipt reconciliation;
- departure versus actual receipt;
- ownership versus custody scope;
- the combined sample’s material scope;
- the North-only completeness boundary.

RAW reconstructed those source semantics during each fresh run. World and Reference consumers queried or inspected already compiled meanings. This is direct evidence for eliminating repeated native-source semantic reconstruction in the operational sense.

## 6. Work character and amortization

The demonstrated transformation is:

```text
RAW:       source discovery + parsing + cross-source reconciliation + task reasoning
WORLD:     semantic schema discovery + semantic query/derivation + task reasoning
REFERENCE: semantic schema discovery + semantic query/derivation + task reasoning
```

The phrase “compile meaning once → compute over it many times” is supported as a change in where downstream work occurs. It is not yet a demonstrated monetary or token amortization claim. Prior reports show World consumers can use more tool calls for schema exploration, and recorded token counters are often incomplete. The evidence supports reuse of semantic interpretation across fresh consumers, not a quantified savings estimate.

## 7. How close is World consumption to engineered-reference consumption?

On this task set, both OA Worlds and REFERENCE had the same source-free work character and completed all uncertainty-sensitive questions without false closure. REFERENCE had 20/20 question-runs complete against frozen gold, while OA-1/OA-2 had 18/20 due to NQ-01. After challenging the gold, the difference is not cleanly attributable to World construction quality: the reference’s extra quantities are not established by the visible records.

Thus grain provides evidence of downstream behavioral proximity between organic Worlds and a deliberately engineered semantic layer on supported traceability consequences, but not a clean reference superiority result. It also shows that reference construction cost must remain visible: the reference required concepts, relations, identity decisions, source mappings, transformations, derivations, query semantics, uncertainty rules, and evaluator-side materialization before its consumer ran.

## 8. Why OA-1 and OA-2 made the same omissions

The root-cause diagnosis finds no single shared failure.

- For Spout 3, both agents read the field but selected the same coarser loadout abstraction: bin, truck, time, quantity, route. Neither self-test asked for spout-level output. This reflects purpose salience and a common operational abstraction, with a benchmark question demanding finer grain.
- For 15,000/11,000 kg, both agents read the combined movement and the explicit no-allocation rule. Both materialized contributor identity and preserved source-allocation uncertainty. The shared choice is epistemically justified, not a model hallucination.

The full evidence path is in [shared_omission_diagnosis.md](shared_omission_diagnosis.md).

## 9. Were the omissions purpose-critical?

Not in the same sense.

- Spout 3 is a real source-supported fact and a legitimate standard-backed coverage target, but the declared purpose can be performed at bin/truck/loadout-event grain. It is not strictly purpose-critical.
- The 15,000/11,000 split is neither established by host evidence nor required by the purpose. It is not purpose-critical and should not be committed. The frozen gold is over-specified.

Therefore the frozen benchmark coverage verdict remains `PARTIALLY_SUPPORTED`, while the purpose-only interpretation is `SUPPORTED`.

## 10. Kernel pressure

```text
KERNEL PRESSURE: NONE
```

No observed failure demonstrates that the existing Ontology Author kernel cannot represent a purpose-relevant, evidence-supported consequence. Both Worlds represent events, materials, multi-hop flow, temporal intervals, ownership/custody distinctions, grounding, unresolved requirements, scoped completeness, and derived closure. The Spout 3 omission is a constructor abstraction choice. The 15,000/11,000 issue is an evaluator/source-evidence defect. No kernel change is justified.

## 11. Final paper-quality answers

1. **Prior RAW versus World:** prior research already demonstrated source-free World reuse, conditional RAW parity, World advantages on selected programming tasks, RAW advantages against inadequate Worlds, and a shift from native-source reconstruction to semantic querying.
2. **Grain replication:** it replicates zero-source World consumption, preserved uncertainty, and the source-parsing-to-semantic-query work shift under a new grain corpus and two independent Worlds.
3. **New grain result:** two different organic Worlds converge on the same downstream consequences, and a reference arm reveals a benchmark distinction between semantic coverage and evidence-grounded purpose sufficiency.
4. **Correctness:** the evidence supports preservation of supported correctness, not a general World accuracy advantage.
5. **Repeated reconstruction:** yes, native source-specific semantic reconstruction was eliminated for World and Reference consumers in this arm.
6. **Reference proximity:** downstream World consumption is close to reference consumption on supported consequences and uncertainty handling; the reference’s NQ-01 edge is not a clean evidence-grounded advantage.
7. **Shared omissions:** Spout 3 reflects a shared coarser abstraction and missing self-test salience; the quantity split reflects correct conservative interpretation of an unallocated blended movement.
8. **Purpose criticality:** neither frozen partial is necessary to perform the short declared operational purpose; Spout 3 is standard-CQ coverage, and the quantity split is not established at all.
9. **Kernel pressure:** none.
10. **Amortized understanding:** the strongest justified claim is that semantic compilation can move source interpretation and reconciliation into a one-time construction stage, allowing multiple fresh consumers to compute over grounded semantic state without reopening native sources. The evidence does not yet justify universal accuracy dominance, portable schemas, token/tool savings, or monetary ROI.
