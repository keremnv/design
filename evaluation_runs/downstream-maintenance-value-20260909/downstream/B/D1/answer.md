# FEED-2207 source receiving tickets

Grower-feed batch **FEED-2207** was produced in mill run **MILL-2207** from Hearthland intake receipt **HFM-IN-602**. That receipt traces to Prairie Gate loadout **PGE-OUT-5002** (carrier manifest **NS-8848**).

Hopper paperwork for that loadout (**OUT-5002**, bin movement **BM-004**) named two Prairie Gate receiving tickets as the grain sources:

- **WB-390** (receiving record ER-7721, Willow Bend Farms)
- **EF-18** (receiving record ER-7729, East Fork Co-op)

Those are the receiving tickets named on the hopper sheet for the grain the mill processed as FEED-2207.
