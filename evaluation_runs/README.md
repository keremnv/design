# Frozen research evidence

These are historical experiment results, not current product architecture or
active World workspaces. Read the [Core v1 baseline](../docs/CORE_PRODUCT_V1_BASELINE.md)
and [research inventory](../docs/research/README.md) for the current boundary.

Existing transcripts, evaluation tables and manifests retain their original
paths, model names and protocol assumptions. Absolute developer-machine paths
are provenance of those runs, not portable commands or installation requirements.
Large transcripts remain because they are primary evidence; they are not needed
by the Core v1 acceptance gate. New run directories are ignored unless reviewed
and explicitly selected for archival.

[Checkout authority snapshot](checkout-authority-snapshot/README.md) preserves
the source corpus and authority result formerly tracked under `.worlds/`.
Generated Worlds belong in ignored local state, not among product sources.
